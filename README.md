# R6 Recon Amphibot – Team XPED Documentation

This repository contains the technical documentation for the ESP32 Wireless Communication Gateway, my individual subsystem contribution to Team XPED's R6 Recon Amphibot, developed as part of EGR314 Embedded Systems Design.

The documentation covers the complete subsystem development process, including requirements definition, hardware architecture, component selection, power analysis, schematic and PCB design, firmware interfaces, API documentation, verification, and engineering reflections.

https://mihir-patel-64.github.io/

## My Responsibilities

- Designed the ESP32-S3 Wireless Communication Gateway
- Implemented the MQTT ↔ UART communication bridge
- Developed Wi-Fi connectivity and failsafe behavior
- Implemented the camera streaming infrastructure
- Designed the hardware and PCB layout
- Documented firmware architecture and APIs
