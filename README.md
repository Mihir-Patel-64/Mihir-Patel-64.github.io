# Team XPED - R6 Recon Amphibot

This repository hosts my individual technical documentation for the ESP32 Wireless Communication Gateway developed as part of Team XPED's R6 Recon Amphibot project in EGR314 Embedded Systems Design.

The documentation covers the complete design process for my subsystem, including requirements, hardware architecture, component selection, power analysis, PCB design, firmware interfaces, API documentation, verification, and engineering reflections.
